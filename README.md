# ⚽ BADR KOOBRA

## Professional Football Player Portfolio

BADR KOOBRA is a modern football player portfolio website created to showcase the player's profile, statistics, career, clubs, matches, performance, highlights, videos, gallery, and contact information.

## 🚀 Features

- 🏟️ Professional football-inspired Hero section
- 👤 Player Identity
- 📊 Player Statistics
- 🏆 Club History
- ⚽ Match Center
- 📈 Performance Analysis
- 🎬 Match Highlights
- 📸 Player Gallery
- 📱 Fully Responsive Design
- ☰ Mobile Navigation
- ✨ Loading Screen
- 🔝 Back To Top
- 📞 Contact & Social Media

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🎨 Design

The website uses a dark stadium-inspired interface with neon green accents, cinematic effects, modern cards, responsive layouts, and football-focused visuals.
